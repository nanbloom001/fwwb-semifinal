## 五、针对本赛题的分析与建议

### 赛题任务类型
根据赛题配置文件分析：
1. `train_env_conf_standard_locomotion.toml` → **标准运动控制**（速度跟随）
2. `train_env_conf_track_nav.toml` → **赛道导航**（目标点到达）
3. `train_env_conf_track_hier_nav.toml` → **层级导航**（高层目标 + 底层运动）

### 核心参考路径建议

#### 方案 A：直接参考 unitree_rl_gym（运动层）+ 自定义导航
```
底层运动 → unitree_rl_gym/legged_gym 的 Go2 奖励设计
导航层   → go2_omniverse 的 Nav2 层级设计思路
集成     → Isaac Lab manager_based locomotion/velocity 任务框架
```

#### 方案 B：层级 RL（与赛题 track_hier_nav 对应）
```
底层策略 → Walk These Ways（速度命令跟随，步态鲁棒性）
高层策略 → 目标朝向 + 速度命令输出
参考代码 → HimLoco Lab 的双网络架构（可分离训练高/低层）
```

#### 方案 C：Teacher-Student 端到端（与 Extreme Parkour 对齐）
```
特权信息教师策略 → 完整地图信息 + 障碍位置
视觉学生策略     → 仅深度图/激光雷达
蒸馏框架        → RSL-RL 内置的 student-teacher 支持
```

### 关键奖励设计参考（从各项目提炼）

```python
# 标准运动奖励（来自 unitree_rl_gym / legged_gym）
- 速度跟随奖励: r_vel = exp(-|v_cmd - v_actual|²)
- 姿态稳定奖励: r_orientation = -|gravity_projected|²
- 步态平滑奖励: r_action_rate = -|a_t - a_{t-1}|²
- 足端接触奖励: r_contact = symmetry feet contact pattern

# 导航扩展奖励（来自 go2_omniverse / go2_parkour_deploy）
- 目标距离奖励: r_goal = -d(pos, goal)
- 朝向对齐奖励: r_heading = cos(θ_robot, θ_to_goal)
- 障碍惩罚:     r_obstacle = -contact_penalty_on_body
```
